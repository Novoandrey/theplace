> Исполняемый чек-лист из `plan.md`, сгруппированный **по историям** `spec.md` (каждая выкатывается
> самостоятельно, со своим `CHECKPOINT`). Принципы — `constitution.md`. **Реализация — по одной
> задаче за раз** (конституция §10): берём первую `[ ]`, делаем, помечаем `[x]`, останавливаемся.

**Легенда.** `[P1]` MVP · `[P2]` важно · `[P3/later]` потом · `[P]` можно параллельно внутри истории ·
`CHECKPOINT` — история независимо демонстрируема. Фазы (spec §10): **v0** (скилл Claude Chat) →
**v1** (Telegram-бот, *гейт: доступ к Anthropic API*) → **v1.1** (автопостинг, *гейт: запись складских
документов через открытое API QR*) → v2.
