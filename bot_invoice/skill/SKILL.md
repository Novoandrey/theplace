# Анализатор накладных (bot_invoice · v0)

Превращает фото товарной накладной в **готовый к импорту в Quick Resto** документ прихода. Весь цикл
делает один человек — **шеф-повар**; скилл его ведёт и спрашивает по сомнительным местам. Язык и
тон — русский, нейтральный. Деньги внутри — в **копейках** (в файл импорта — в рублях).

Источник правды — Quick Resto. Зеркало номенклатуры — `data/nomenclature_qr.json`; растущая таблица
соответствий — `data/aliases.json`. Эталон формата файла — `samples/QR_pn135_format_sample.xlsx`.
Пути ниже — относительно папки `bot_invoice/`.

## Конвейер (по шагам)

1. **Вход** — одна накладная = одно или несколько изображений/PDF (страницы склеиваются в один документ).
2. **Извлечение** — по чек-листу ниже в канонический JSON (см. `samples/EK-2029_extracted.json`).
3. **Проверка арифметики** — `tools/validate_invoice.py`.
4. **Сопоставление** — `tools/match_nomenclature.py` (артикул Quick Resto на каждую строку).
5. **Пересчёт** — кол-во и цена в учётную единицу позиции; НДС — из накладной.
6. **Вопросы человеку** — по флагам (низкая уверенность, неоднозначный пересчёт, спорный артикул).
7. **Файл** — `tools/to_qr_import.py` → xlsx + csv в раскладке ПН135; сверка итогов с накладной.

Цифры, сверку, сопоставление и сборку файла делают **детерминированные инструменты** — не считай
суммы «в уме». Скилл отвечает за извлечение, вопросы и решения с человеком.

## Шаг 2. Извлечение — чек-лист

**Шапка:** номер документа, дата, основание (заказ), поставщик/грузоотправитель (контрагент),
получатель/плательщик, ИНН (где есть). Поставщик может не иметь ИНН на бланке — это норма (берётся
из справочника контрагентов Quick Resto). Не путай стороны: грузоотправитель/поставщик — продавец;
грузополучатель/плательщик — покупатель (наша сторона).

**Строки (на каждую):** № · наименование (с брендом/фасовкой как на бумаге) · код поставщика ·
количество · единица · цена · ставка НДС · суммы (без НДС, НДС, с НДС). Дополнительно, если есть:
ОКЕИ, «в одном месте», «мест», масса брутто/нетто.

**Итоги:** мест, масса брутто, количество, суммы (без НДС / НДС / с НДС), сумма прописью.

**Частые ошибки распознавания — помечай `confidence` и `note`, а не «дорисовывай»:**
- Единица vs ОКЕИ: код ОКЕИ 796 = «шт», 166 = «кг» — сверяй с графой единицы.
- Усечённые/нестандартные коды (например, без буквенного префикса) — помечай, не достраивай.
- Брутто/нетто и «в одном месте» бывают **недостоверны** (вес со стеклом/упаковкой, опечатки поставщика).
- Штамп/печать или правка ручкой поверх текста (часто перекрывает бренд) — помечай как нечитаемое.

Записывай в канонический JSON (деньги в копейках): `document`, стороны, `items[]` (поля выше +
`confidence` `high|med|low` + `note` + `qr_nomenclature_match`), `totals`, `extraction_flags[]`.

## Шаг 3. Проверка арифметики

```
python3 tools/validate_invoice.py <канонический.json>
```
Проверяет построчно `кол-во×цена=сумма`, `НДС`, `с НДС=без НДС+НДС` и сверяет 6 итогов (допуски на
округление). **Жёсткие расхождения — стоп до правки** (вернись к извлечению/спроси человека).
`confidence=med/low` выводятся как предупреждения для ручной проверки.

## Шаг 4. Сопоставление с номенклатурой

Ключ — **артикул Quick Resto** (не код поставщика). Для каждой строки:
```
python3 tools/match_nomenclature.py "ключевые слова из названия"   # напр.: "фарш говяж 70 30"
python3 tools/match_nomenclature.py --self-test                    # прогон по строкам EK-2029
```
Порядок: сперва `data/aliases.json` (точное соответствие, метка `alias`), затем нечёткий матч по
названию (`fuzzy`). Метка `weak` — низкая уверенность: вероятно **нет в номенклатуре** или спорно →
спроси человека (завести позицию в Quick Resto вручную или пропустить строку; автоматически не
создаём). Записывай выбранный артикул в `qr.art`/`qr_nomenclature_match`.

**Подтверждённое сопоставление пополняй в `data/aliases.json`** (`keywords` → `art`, `qr_name`,
`note`) — со временем вопросов меньше.

## Шаг 5. Пересчёт единиц и НДС

- **Единица** — берётся из карточки позиции Quick Resto (`unit` в `nomenclature_qr.json`): в основном
  `кг`; исключения — `шт` (яйца, хлеб, упаковка) и `л` (часть масел).
- **Упаковки → базовая единица:** разбери размер упаковки из названия (например, «(2,000 кг) упак.4 шт»,
  «5 л / 4,7 кг») и переведи кол-во.
- **Объём → кг** (позиция в кг, а накладная в л/мл): по согласованию — **лёгкий счёт** (1 л ≈ 1 кг),
  плотность или **фасовка** Quick Resto. **Любой неоднозначный пересчёт — подтверждай у человека.**
- **Цена в файл — «с НДС» (ведущая):** считается как `Сумма с НДС ÷ Кол-во` (это делает генератор);
  несколько копеек расхождения от округления — норма.
- **Ставка НДС — из накладной поставщика как есть** (10%/22%/5% и т.п.), не «исправляй» (с 2026 базовая
  ставка — 22%).

Решённое сопоставление и пересчёт записывай в объект `qr` каждой строки:
`{"art","name","type":"Ингредиент","unit","qty","note"}`.

## Шаг 6. Вопросы человеку (политика)

- **Спрашивай, не выдумывай.** Нечитаемое/перекрытое/неоднозначное → конкретный вопрос; не
  подставляй значение.
- **Финансовая строка важнее справочных масс.** При кривых массах/упаковке считай по сумме строки
  (`кол-во×цена=сумма`, она всегда сходится) и помечай расхождение.
- Сгруппируй флаги в короткий список вопросов; человек правит/подтверждает; после правок —
  пересобери файл. Любое поле можно поправить до сборки файла.

## Шаг 7. Файл импорта

```
python3 tools/to_qr_import.py <канонический.json> --out samples/<имя>_qr_import
```
Пишет `*.xlsx` и `*.csv` в раскладке ПН135 (`№ · Артикул · Тип · Наименование · Кол-во+ед · Цена с
НДС · Сумма без НДС · НДС · Сумма НДС · Сумма с НДС`), сверяет итоги файла с итогами накладной и
выводит строки-флаги и нерешённые позиции. Код возврата 0 — собрано и итоги сходятся.

**Оговорка:** есть только *экспортная* раскладка ПН135. Перед боевым применением файл нужно прогнать
**пробным импортом** в тестовую приходную Quick Resto; при расхождении шаблона импорта — поправить колонки.

## Что отдать человеку

Готовый файл импорта + короткий лист проверки (что подтвердить). Шеф-повар импортирует файл в Quick
Resto (Склад → складские документы → приходная) и проводит её. Пример всего цикла — папка `samples/`
(накладная EK-2029).
