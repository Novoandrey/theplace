# INSTRUCTIONS.md

Рабочий репозиторий проекта **«The Place»** — AI-автоматизация для кофейни
(Telegram-боты, парсеры накладных, дашборды поверх Quick Resto и т.п.).

Это самостоятельный проект. Система карточек / «второй мозг» (`data/cards/…`)
к нему **не относится** — это другой проект.

## Начало сессии

1. Склонировать репо. PAT берётся из bootstrap-сообщения и **в репозитории не хранится**:
   ```
   git clone https://x-access-token:<PAT>@github.com/Novoandrey/theplace.git
   ```
2. Настроить identity:
   ```
   git config user.name "Claude"
   git config user.email "claude@anthropic.com"
   ```
3. Прочитать этот файл.

## Работа с ветками

- В `main` напрямую **не коммитить и не пушить**. Ветку `main` ведёт Andrey.
- Под каждую задачу — отдельная ветка от свежего `main`:
  ```
  git checkout main && git pull
  git checkout -b claude/<short-slug>
  ```
  Имя ветки — латиницей, kebab-case, с префиксом `claude/` (например `claude/invoice-parser`).
- Работа коммитится в эту ветку, ветка пушится в origin:
  ```
  git push -u origin claude/<short-slug>
  ```
- В конце Claude называет ветку и кратко описывает, что в ней.
  Andrey сам ревьюит и мёржит/пушит её в `main`.
- Коммиты небольшие и осмысленные; сообщения — в нейтральном тоне.
