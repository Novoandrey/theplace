# INSTRUCTIONS — точка входа сессии

Порядок для новой сессии (после клонирования репозитория и настройки git identity
Claude / claude@anthropic.com):

1. **`HANDOFF.md`** — текущее состояние проекта, ключевые решения, что сделано и следующий шаг.
2. **`constitution.md`** — принципы уровня проекта (обязательны к соблюдению).
3. По активному боту — **`bot_pickup/spec.md`**, **`research.md`**, **`plan.md`**.

Метод работы — **spec-driven** (`Constitution → Specify → Clarify → Plan → Tasks → Analyze →
Implement`). Каждый бот живёт в своей папке `bot_<name>/`; планировочные доки — внутри неё.

Файлы создаём в `/mnt/user-data/outputs/...`, показываем пользователю и **коммитим в этот
репозиторий** (аддитивно, осмысленными коммитами; без force/удаления чужой истории).

> Андрей: этот файл можно расширять под свои правила работы.
